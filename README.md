#  LearnVerse - WebXR Educational Platform
# Overview
<br>
LearnVerse is a WebXR-based educational platform that enhances learning through immersive 3D visualizations and interactive experiences. It helps students understand complex technical concepts in subjects such as Data Structures, Operating Systems, and Computer Networks directly through a web browser.
<br>

# Features
-Interactive 3D learning environments<br>
-WebXR-based immersive educational experiences<br>
-Visual demonstrations of technical concepts<br>
-Secure user authentication using JWT<br>
-Responsive and user-friendly interface<br>
-Real-time frontend-backend integration<br>

# Technologies Used
Frontend: React.js, Tailwind CSS, Vite<br>
Backend: Node.js, Express.js<br>
3D/WebXR: A-Frame, WebXR<br>
Authentication: JWT, bcrypt.JS<br>

# Modules
Data Structures Visualization<br>
Operating Systems Concepts<br>
Computer Networks Simulation<br>

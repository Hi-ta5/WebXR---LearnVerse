# LearnVerse — WebXR Tutor

> An immersive WebXR-based learning environment designed to help engineering students understand complex concepts through interactive 3D visualization, structured learning modules, quizzes, and an AI-powered learning assistant.

## 📌 Overview

LearnVerse is a web-based immersive learning platform that combines **WebXR, interactive 3D models, quizzes, and AI-assisted learning** to create a more engaging way of studying engineering concepts.

The platform allows students to explore academic subjects through interactive modules instead of relying only on traditional text-based learning.

## ✨ Key Features

* 🥽 Interactive WebXR-based learning environment
* 🌐 3D visualization of technical concepts
* 📚 Subject-wise learning modules
* 📝 Interactive quizzes with multiple questions
* 📊 Learning progress tracking
* 🔐 User authentication
* 🤖 AI-powered learning assistant
* 🎯 Interactive dashboard
* 💻 Responsive web interface

## 🎓 Learning Modules

LearnVerse is designed to support multiple engineering subjects and their individual learning modules.

Current project modules include areas such as:

* Computer Networks
* Operating Systems
* Data Structures
* Object-Oriented Programming
* Database Management Systems

Each module can combine:

**Concept → 3D Visualization → Explanation → Quiz**

## 🥽 WebXR Learning

The core idea of LearnVerse is to make technical concepts easier to visualize.

Instead of studying a concept only through diagrams or text, students can interact with a 3D representation of the concept inside the browser.

The project uses **A-Frame and WebXR technologies** to create the immersive learning experience.

## 🤖 AI Learning Assistant

LearnVerse includes an AI-powered learning assistant designed to provide additional support while learning.

Students can use the assistant to:

* Ask questions about concepts
* Get additional explanations
* Clarify difficult topics
* Explore learning content interactively

The assistant is kept separate from quiz sessions to maintain the purpose of assessment.

## 📝 Interactive Quizzes

Each learning module can include an interactive quiz to test the student's understanding.

The quiz system provides:

* Multiple-choice questions
* Immediate feedback
* Score calculation
* Completion tracking

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Vanshikaa4701/LearnVerse-WebXR.git
```

### 2. Navigate into the project

```bash
cd LearnVerse-WebXR
```

### 3. Install dependencies

Install the project dependencies according to the provided package configuration.

```bash
npm install
```

If the frontend and backend use separate package files, install their dependencies inside their respective directories as well:

```bash
cd client
npm install
```

```bash
cd ../server
npm install
```

### 4. Start the application

Use the project's development/start commands configured in the repository.

The frontend and backend may run on separate local ports during development.
